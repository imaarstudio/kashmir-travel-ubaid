# Image slots

Files here are picked up automatically: each `<img>` carries
`onerror="this.remove()"`, so a missing file falls back to the scene-matched
gradient underneath and a correctly named file takes over with no code change.

### Note: `pampore.jpg` contradicts its copy

The photograph is a **mustard** field (yellow, and it blooms in spring). The card
next to it currently reads:

> The saffron fields, purple for about three weeks from late October — the most
> expensive spice on earth being picked by hand, half an hour from Srinagar.

The place is right — the photographer titled it in Pampore — but yellow mustard
under copy promising purple saffron is a contradiction a reader will notice.
Either swap in a saffron-bloom photograph, or rewrite the card around the mustard
fields and mention saffron as the autumn reason to return.

## Licensing

Everything here must be Ubaid's own photography or properly licensed stock.

**Do not** take images from hotel listings, booking sites, other agencies' pages,
Instagram or image search. Those are owned by the hotel, the platform or the
photographer and are licensed only for that listing — using one on this site is a
copyright exposure that lands on the client, not on whoever pasted the link.
